# 📖 About The Project

Parampara Bazaar is a next-generation cultural commerce platform designed to digitally empower Indian artisans, handmade product creators, traditional vendors, and local businesses.

The platform aims to bridge the gap between traditional craftsmanship and modern consumers by providing a scalable digital ecosystem where culture, heritage, and technology coexist seamlessly.

This project combines modern full-stack architecture with cultural preservation to create a meaningful and impactful e-commerce solution.

---

# 🌟 Vision

The vision behind Parampara Bazaar is to:

- Promote Indian handicrafts globally
- Support local artisans economically
- Preserve traditional culture digitally
- Build a scalable marketplace ecosystem
- Enable direct vendor-to-customer interaction
- Modernize traditional commerce using technology

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/Annshikaa/parampara-bazaar.git
```

---

## Install Dependencies

```bash
npm install
```

---

## Setup Environment Variables

Create a `.env.local` file in the root directory.

Example:

```env
DATABASE_URL=your_postgresql_url
REDIS_URL=your_redis_url
JWT_SECRET=your_secret
NEXT_PUBLIC_FIREBASE_API_KEY=your_key
RAZORPAY_KEY_ID=your_key
```

---

## Run Development Server

```bash
npm run dev
```
